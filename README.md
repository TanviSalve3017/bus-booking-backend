# Online Bus Reservation System - Backend

Ha project cha backend part aahe jo Node.js aani Express.js madhe banvla aahe. 

## Tech Stack
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MySQL

## Features
- User Authentication (Login/Signup)
- Bus Search API
- Seat Booking Logic

## Setup
1. Clone this repo
2. Run `npm install`
3. Start server using `node index.js`
